## What is Nytlex.js?

**Nytlex.js** is a modern full-stack web framework designed for developers who want performance, flexibility, and simplicity without sacrificing scalability.

Build applications using **React**, **Vue**, or **Svelte** while keeping a consistent development experience across the entire stack.

From small projects to enterprise platforms, Nytlex provides the tools needed to build production-ready applications with minimal friction and maximum productivity.

## Native HTTP/3 Support

Nytlex includes native HTTP/3 support through its networking architecture, allowing applications to take advantage of the latest generation of web transport technology when desired.

The framework remains fully compatible with traditional deployment strategies, reverse proxies, and modern hosting environments.
